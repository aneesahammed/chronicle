SWE-Duel: Towards a Self-Scaling Arena for Coding Agents

SWE-Duel proposes a self-scaling benchmark where coding agents evaluate each other in real-time to prevent data leakage and static saturation.

Traditional coding benchmarks suffer from data leakage and saturation as models improve. SWE-Duel addresses this by generating tasks and oracles at evaluation time. In this arena, two agents engage in mirrored Red-Blue turns, working on real repositories within isolated sessions to test capabilities dynamically.
